# Active classic card illustrations

Imported20 October2026 for the Kod Dushi website. Each original image, its source page, licence, native dimensions, output dimensions and SHA256 are recorded in `classic-decks-manifest.json`. No image was enlarged to claim a higher scan resolution. WebP files preserve the scan's native width/height; original scans are cached locally for reproducibility. SVG playing-card originals remain vectors.

- **Rider–Waite–Smith,78 cards.** Artwork by Pamela Colman Smith,1910. High-resolution TaionWC scans on Wikimedia Commons, approximately1090–1144×1919–1920. Source: https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC) . Wikimedia marks these images as public domain. Example source page: https://commons.wikimedia.org/wiki/File:RWS_Tarot_00_Fool.jpg .
- **Petit Lenormand,36 cards.** Historical public-domain deck digitised by Bibliothèque nationale de France, collection`btv1b10529584r`, reproduced on Wikimedia Commons. Odd-numbered scans1–71 are the36 faces; even scans are backs. Native scans are around1440×2130. Example: https://commons.wikimedia.org/wiki/File:Jeu_de_cartes_divinatoire,_dit_%22Petit_Lenormand%22_-_estampe_-_btv1b10529584r_(01_of_74).jpg . This historical deck is not the planned original “Secret Garden” deck.
- **Playing cards,52 faces;36-card subset.** AustinGabriel's Public Domain and CC0 Playing Cards, using the author's standard fronts. Source: https://github.com/AustinGabriel/Public-Domain-and-CC0-Playing-Cards . CC0-1.0. The full licence and the author's source-credit README are retained in `cards/playing-classic-v1/`. The36-card variant includes ranks6–Ace of each of the four suits. No jokers. Original SVG files scale without a fixed pixel limit; web derivatives are rendered at2048pixels wide for the site's stable image URLs.

The website keeps stable public face URLs under`cards/midnight-art-nouveau-v1/` to preserve the existing temporary preview origin and saved browser archives. **The folder name is historical: active face bytes are the classic artworks above, replacing the prior generated faces.** Canonical originals and converted master files are also stored in the separate `classic-rws-v1`, `lenormand-classic-v1` and `playing-classic-v1` directories. Thumbnail derivatives are for previews; full-size faces remain available in card details.

The minimal rose card back is a separate project-generated asset, documented in `../docs/rose-dawn-card-back-v2.md`. Source licences and provenance of the prior generated deck remain historical documentation, not attribution for these replacement faces.
