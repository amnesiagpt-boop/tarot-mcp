# Soimoi Tarot

78 digital illustrations by Mike Koz (https://koz.tv/), CC BY 4.0.

Source: https://github.com/mixvlad/TarotCards/tree/840b84d012c6b74dc1634fa2d00d1b21f5b28093/tarot/soimoi

Artwork was created by the author using a generative image model. Used here as contemporary illustrations for the classic 78-card system. Conversion: JPEG to full-resolution WebP, plus 360px thumbnails; no cropping, color changes or retouching. Active files retain stable compatibility paths; see assets/modern-decks-manifest.json for per-card sources, dimensions and hashes.
